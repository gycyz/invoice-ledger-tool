# 进项发票台账工具

把电子税务局「全量发票查询」导出的 xlsx，变成一份会计能直接入账的进项台账 + 一份能讲清异常的核对报告。一次运行，输出报告、台账、异常清单。

面向的场景：一批（几十到几百张）进项票要按月整理、要算可抵扣税额、要解释"为什么合计和税局票面对不上"。手工做通常要一整天，这个脚本几秒钟。

## 它做什么

1. **读**：从导出的多 sheet 结果里按关键词识别各类票种（专票/普票/铁路/航空/旅客运输/红字），不依赖 sheet 顺序。
2. **核**：12 条规则逐票逐行核对——发票级与明细级合计是否一致、税额是否等于金额×税率、红冲是否成对、开票日期是否越界、疑似重复报票、含不征税项目等。
3. **出**：一份 12 页的台账底稿（openpyxl 生成，列宽自适应、金额列不出现 `####`）和一份 markdown 报告。

## 快速开始

```bat
python 脚本\invoice_ledger.py 原始数据\导出表.xlsx
```

限定统计区间（推荐，避免跨期票混入）：

```bat
python 脚本\invoice_ledger.py 原始数据\导出表.xlsx --start 2026-09-01 --end 2026-09-30
```

产物落在 `产物\当天日期\`：`核对验证报告.md`、`进项发票台账.xlsx`、`异常清单.csv`。

## 台账里有什么

| sheet | 内容 |
|---|---|
| 说明 | 数据源、区间、口径、异常条数（交接第一眼看的页） |
| 发票台账 | 一票一行：号码、日期、销方、票种、税率、金额、税额、价税合计、票面价税合计、有效标记、费用类别 |
| 明细表 | 原始明细行（一票多行） |
| 异常清单 | 高/中/低三级的检查结果 |
| 月度汇总 / 票种税率汇总 / 销方汇总 / 费用类别汇总 | 申报前对总账、算可抵扣、供应商与费用结构分析 |
| 差旅明细 / 差旅按人汇总 / 差旅待补 | 客运、铁路、航空逐行程；按人汇总；有票无行程待补清单 |
| 红冲清单 | 作废蓝票 + 红字票，含关联票号 |

## 两条容易搞错的口径

- **价税合计 vs 票面价税合计**：前者是明细行累加（含不征税项目，如航空票的民航发展基金），后者扣掉不征税项目、与税局票面一致。费用统计用前者，进项申报对账用后者。差额全部来自不征税项目，报告里逐票列出。
- **红冲**：红字票按负数计入，蓝票保留原值，二者自然抵销。不要为了"看起来干净"删掉红字行或作废蓝票行，否则合计会错。

可抵扣税额是**参考口径**（专票 + 铁路/航空/旅客运输按票面税额，普票计 0，免税/0%/不征税不计入），实际申报以会计确认为准。

## 换一批数据 / 换一个客户

- 导出表的 sheet 名不同：改脚本顶部 `SHEET_KINDS` 的关键词。
- 列名不同（「销方名称」写成「销售方名称」）：往 `ALIASES` 里加别名。
- 费用归类不顺手：改 `EXPENSE_RULES`，规则自上而下先命中先归类。

## 关于本仓库

- 仓库里只有脚本、运行脚本和说明，**不含任何客户数据**：`原始数据/`、`产物/` 已由 `.gitignore` 排除。
- 完整的使用方法、目录结构与已知限制见 [使用说明.md](使用说明.md)。
- 已知限制：导出表的数电发票号码是 19 位数值，超过 Excel 15 位精度会失真，脚本改用（销方识别号 + 开票日期 + 价税合计）做匹配；差旅明细只覆盖导出表里带行程的票，合并开票的票进"差旅待补"。
